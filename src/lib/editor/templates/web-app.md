## Getting started

### Prerequisites

- [Node.js](https://nodejs.org) 20 or newer
- npm, pnpm or yarn

### Installation

```bash
git clone https://github.com/your-name/project-name.git
cd project-name
npm install
cp .env.example .env
npm run dev
```

Then open <http://localhost:5173> in your browser.

> [!TIP]
> Run `npm run build` to create a production build in `dist/`.
