# Lumen UI

A tiny, accessible component kit that makes any web app feel polished in minutes.

![Version](https://img.shields.io/badge/version-3.2.0-8B5CF6) ![Build](https://img.shields.io/badge/build-passing-22C55E) ![Size](https://img.shields.io/badge/gzip-9.8%20kB-0EA5E9) ![Licence](https://img.shields.io/badge/licence-MIT-F59E0B)

## Features

- 🎨 **Themeable**: one CSS variable changes the whole palette
- ♿ **Accessible**: AA contrast and full keyboard support
- ⚡ **Tiny**: under 10 kB with zero dependencies
- 🌍 **Global**: right-to-left layouts out of the box

## Quick start

```tsx
import { Button } from 'lumen-ui';

export const Save = () => <Button tone="violet">Save changes</Button>;
```
