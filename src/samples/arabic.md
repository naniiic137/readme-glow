# مِداد

**محرّر ملاحظات أنيق يعمل دون اتصال، ويكتب بالعربية كما يكتب بأيّ لغة أخرى.**

![PWA](https://img.shields.io/badge/PWA-ready-5A0FC8?logo=pwa&logoColor=white) ![RTL](https://img.shields.io/badge/RTL-native-0F766E) ![Licence](https://img.shields.io/badge/licence-MIT-B45309)

![غلاف مِداد: زخرفة هندسية بألوان الحبر والذهب](docs/cover.svg "مِداد: اكتب بحرّية، واحفظ بأمان")

مِداد تطبيق ويب خفيف لتدوين الملاحظات بصيغة Markdown. يعمل في المتصفح حتى دون اتصال بالإنترنت، ويحفظ ملاحظاتك على جهازك وحدك. صُمّم منذ البداية للكتابة بالعربية، مع دعم كامل للنصوص الثنائية الاتجاه التي تمزج العربية بالإنجليزية والأرقام.

## المزايا

- **يعمل دون اتصال**: ثبّته تطبيقاً على حاسوبك أو هاتفك واكتب في أيّ مكان
- **خصوصية تامّة**: لا حسابات ولا خوادم، فملاحظاتك لا تغادر جهازك
- **دعم أصيل للعربية**: اتجاه تلقائي لكلّ فقرة، وخطوط نسخ واضحة ومريحة للعين
- **بحث فوري** في آلاف الملاحظات، يتجاهل التشكيل واختلاف صور الهمزة
- **تصدير** إلى HTML وPDF وMarkdown بنقرة واحدة

## التثبيت

تحتاج إلى Node.js بالإصدار 20 أو أحدث، ثم نفّذ الأوامر التالية:

```bash
git clone https://github.com/midad-app/midad.git
cd midad
npm install
npm run dev
```

بعد ذلك افتح العنوان `http://localhost:5173` في متصفحك وابدأ الكتابة.

> [!TIP]
> اضغط <kbd>Ctrl</kbd> + <kbd>K</kbd> لفتح لوحة الأوامر والبحث في ملاحظاتك من أيّ مكان في التطبيق.

## اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
| :------- | :------ |
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | ملاحظة جديدة |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | خط عريض |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> | تبديل اتجاه الفقرة |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | تصدير الملاحظة |

> [!NOTE]
> تُحفظ الملاحظات تلقائياً بعد كلّ تعديل، فلا حاجة إلى زرّ للحفظ.

## المساهمة

نرحّب بكلّ مساهمة، من تصحيح خطأ إملائي إلى ميزة جديدة. افتح نقاشاً قبل التغييرات الكبيرة، وتأكّد من نجاح الاختبارات بالأمر `npm test` قبل إرسال طلب الدمج.
